# Объединение файлов

Программа запускается из командной строки Терминала. 
В качестве аргументов получает имена файлов. Эти файлы 
последовательно объединяются в один и сохраняются на диске.

Используется:
1) Библиотека: sys
2) Метод: argv(): list - список аргументов, переданных при запуске программы
