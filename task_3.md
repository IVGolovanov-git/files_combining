**Название**

Домашнее задание №85: Приготовьте зелье невидимости

**Задача**

Гермионе выпала первая задача — она должна приготовить зелье невидимости. У этого зелья несложный рецепт, но нужно быть очень внимательной.

Гермионе нужно помешивать зелье конкретное количество раз, чтобы оно получилось правильным. Она помечает все помешивания на пергаменте. Общее количество помешиваний должно соответствовать одному из условий:

— делится на 4 и не делится на 100;

— делится на 400.

Напишите функцию potion_check(), которая проверит, помешала ли Гермиона зелье правильное количество раз. Она должна принимать на вход один аргумент — число, которое обозначает, сколько раз Гермиона помешала зелье. В качестве результата работы функции верните yes, если количество помешиваний верное, или no в обратном случае. Используйте операторы and и or, чтобы скомбинировать несколько условий в одном if.

**Решение**

# Программа проверяет одновременное 
# выполнение нескольких условий


def potion_check(stirings):
  if ((stirings % 4 == 0) and (stirings % 100 != 0)) or (stirings % 400 == 0):
    return 'yes'
  else:
    return 'no'

print(potion_check(80))

**Подсказки**

Чтобы найти остаток от деления одного числа на другое, используйте %.

Используйте логический оператор or, если необходимо, чтобы выполнилось хотя бы одно из условий.

Используйте логический оператор and, если необходимо, чтобы выполнились оба условия.
