**Название**

Домашнее задание №83: Выберите дни для поиска крестражей

**Задача**

Гарри, Рон и Гермиона отправляются на поиски крестражей. Как им удалось узнать, один из крестражей спрятан в хранилище Гринготтса — специального банка для волшебников.

Друзья решили использовать зелье невидимости. Лучше всего это зелье работает в туманную погоду.

Помогите волшебникам выбрать дни для поиска крестражей. Создайте функцию search_day(), которая посчитает количество туманных дней в списке. Она принимает в качестве аргумента список с предположительной влажностью воздуха на ближайшие пять дней. Например, такой: 76, 89, 91, 32, 10. Если влажность превышает 80%, день считается туманным. Верните список с порядковыми номерами туманных дней. Номера дней считайте с нуля.

**Решение**

# функция принимает список с указанием влажности воздуха оп дням
# возвращает индексы дней с влажностью более 80%

def search_day(five_days):
  foggy = []
  for d in range(0, len(five_days)):
    if int(five_days[d]) > 80:
      foggy.append(d)
  return foggy

fd = [76, 89, 91, 32, 10]
print(search_day(fd))

**Подсказки**

Используйте условный оператор if, чтобы проверить, превышает ли влажность воздуха 80% в тот или иной день.
